# 통계 데이터 출처 (`corpus/stats/`)

이 디렉터리의 CSV는 **RAG 코퍼스가 아닙니다.** 기획서 §3장의 시장 규모 서술과
부록 B의 사실 검증(`docs/fact-check.md`)을 1차 출처로 뒷받침하는 배경 통계입니다.
청킹·임베딩 대상이 아니며, RAG 원문은 `corpus/raw/`에 따로 둡니다.

## 원본 처리 방침

- 원본은 **파일명이 한국어이고 내용도 CP949**였습니다. `corpus/scripts/00_convert_stats.py`로
  파일명을 영문화하고 UTF-8로 변환했습니다.
- **원본 CP949 바이트는 커밋하지 않습니다.** 공공데이터포털에서 재다운로드 가능하고,
  아래 sha256으로 동일성을 검증할 수 있습니다. 재현하려면 원본을
  `corpus/stats/_incoming/`(gitignore)에 넣고 변환 스크립트를 실행하세요.
- **컬럼명은 한국어 원문 그대로 둡니다.** 원문 충실성이 근거 기반 서비스에서 더 중요하고,
  컬럼 의미는 아래 표에 남깁니다.
- sha256이 달라지면 출처에서 데이터가 갱신된 것입니다. 그때는 이 파일과
  `docs/fact-check.md`의 수치를 **반드시 다시 확인**해야 합니다.

확보일: 2026-08-11 · 변환일: 2026-08-11

> ⚠️ **출처 URL 미기재.** 아래 4건의 공공데이터포털 데이터셋 URL을 아직 채우지 못했습니다.
> 발표 심사에서 "이 수치 어디서 왔냐"는 질문에 URL 없이는 답할 수 없으므로,
> 원본을 내려받은 이력에서 URL을 찾아 각 항목의 `출처 URL` 칸을 채워야 합니다.
> (`docs/fact-check.md`의 B1·B10도 같은 URL을 참조합니다.)
